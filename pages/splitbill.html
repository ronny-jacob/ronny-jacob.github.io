SplitBill

A bill splitter I built for the food my friends and I order, now live.

Problem
When a group orders food, people eat different items. Who pays, and how much, changes every time.
I built
A web app where you scan or upload a photo of the bill, or type the items in, tap who ate each item and see what each person owes.
Evidence
Reads the bills I have tried correctly. A few people use it. Observed No accuracy or usage numbers yet.
Next
Measure the scan on a set of real bills before claiming more.

Decisions

  • An image model instead of OCR. Plain OCR methods did not work on these bills, so the scan uses an image model on Google Cloud.
  • Tap names to assign items. Tapping several names on one item shares it between them.
  • Manual entry as a fallback, so a bad photo does not block the split.

Limits

  • Scan accuracy is my own observation, not a measured rate.
  • I have no usage numbers, only that a few people use it.
