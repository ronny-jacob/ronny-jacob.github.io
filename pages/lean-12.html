Lean 12

A personal tool I built for myself, now live.

Problem
A 12-week plan only works if I remember which session is next, what I lifted last time and how my joints felt.
I built
A workout log that suggests the next session, records sets, reps in reserve and joint pain, and runs the rest timer.
Evidence
None to report. One user, no outcome measure.
Next
Separate personal settings from code so it can be shared, and add backup.

Decisions

  • A rotation that forgives missed days. Sessions A, B, C run Monday, Wednesday, Friday, and the app suggests the next one.
  • Effort and pain after every exercise, so the next suggestion and any swap are grounded in how it went.
  • A rule-based next step: a heavier load once every set reaches the top of the rep range.

Limits

  • Data lives on one device. The rules are simple, personal and not clinically validated.
  • Exercise data is credited in the app to RepDB (repdb.co). Anyone who opens it keeps their own logs in their own browser.
