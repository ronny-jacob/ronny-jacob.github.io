Invisalign Tracker

Built independently. Sole product owner and builder.

Problem
A daily wear target is easy to miss when every tray removal means mental arithmetic.
I built
A local-first app. Log minutes out; it shows today’s status, what happens if you stop now, and the longest next removal that keeps the day on track.
Evidence
75 of 75 rule tests pass, including every worked example in my spec. Data stays on the device.
Next
Configurable rules, an optional reminder, and testing with other aligner wearers.

A tracking tool with rules I defined, not medical advice. Screenshots use sample data.

Decisions

  • The app does the thinking. You type minutes; it recalculates the day.
  • Deterministic rules, no AI. The same input always gives the same answer, so the rules can be tested.
  • Raw events are the source of truth. Editing an old removal corrects that day, the streaks and the insights.
  • Local-first. Data stays in the browser, with JSON and CSV export.
  • I changed my own spec once (v1.6.0): a single 41–60 minute removal no longer fails a day if it is the only one in seven days.

Limits

  • No cross-device sync; switching phones needs an export and import.
  • The rules suit my plan. Other plans would need configurable rules.
  • No user research and no usage data.
